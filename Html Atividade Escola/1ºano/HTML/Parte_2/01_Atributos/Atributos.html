Atributos HTML são informações adicionais colocadas dentro da tag de abertura para modificar o comportamento ou a aparência de um elemento

    Os principais atributos são:

  1. class;
  2. ID;
  3. style;
  4. href;
  5. src;
  6. alt;
  7. placeholder.

Vou aprofundar os tipos de atributos depois, existem os globais e os booleanos;

Os atributos globais definem o escopo de onde o atributo pode ser usado, enquanto os atributos booleanos definem a forma como o atributo é ativado.
