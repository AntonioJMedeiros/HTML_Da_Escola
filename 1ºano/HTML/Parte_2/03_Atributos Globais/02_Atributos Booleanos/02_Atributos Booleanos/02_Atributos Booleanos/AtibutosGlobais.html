Atributos Globais

Os atributos globais em HTML são aqueles que podem ser utilizados em qualquer elemento HTML, independentemente de qual seja a tag.

    Principais características dos atributos globais:

  • Eles funcionam de forma universal em toda a página.
  • Servem para estilização, identificação, acessibilidade e comportamento geral.
  • Mesmo que uma tag não precise dele diretamente, o navegador reconhecerá o atributo como válido.

Exemplos de Atributos Globais

  1. ID Define um identificador exclusivo para um elemento em toda a página.
  2. class: Associa o elemento a uma ou mais classes de estilização (CSS) ou manipulação (JavaScript).
  3. style: Permite aplicar regras de estilo CSS diretamente no elemento.
  4. title: Adiciona uma informação extra sobre o elemento, geralmente exibida como um balão de texto (tooltip) quando o mouse passa por cima.
  5. hidden: Um atributo booleano global que esconde o elemento da tela.
  6. contenteditable: Permite que o usuário edite o conteúdo de texto do elemento diretamente no navegador.
