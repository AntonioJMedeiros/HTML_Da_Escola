Atributos booleanoss

Os atributos booleanos em HTML são os atributos que representam os valores verdadeiro/true ou false/falso.

    Se o atributo estiver presente, ele pode ter uma das seguintes formas:

  • O nome do atributo sozinho; por exemplo, attribute, o que significa que seu valor implícito é a string vazia.
  • O atributo com o valor de uma string vazia; por exemplo,attribute=""
  • O atributo com o valor do próprio nome do atributo, sem espaços em branco no início ou no final e ignorando maiúsculas e minúsculas; por exemplo, attribute="attribute",attribute="ATTRIBUTE"

Exemplos de Atributos

  1. Checked: Marca uma caixa de seleção.
  2. Disabled: Desabilita um campo ou botão.
  3. Required: Torna o preenchimento de um campo obrigatório.
  4. Readonly: Deixa o campo apenas para leitura.
